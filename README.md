# SHI Business Intelligence Dashboard

Situs: halaman ini di-host dengan GitHub Pages.

## Isi repository

```
index.html                     ← dashboard (satu file, berisi semua teks, gambar, booklet & video 720p)
assets/
  SHC_Purchasing_Solution_Proposal_2026.pdf   ← untuk tombol Buka / Unduh PDF
  hero.mp4                                    ← untuk tombol Unduh video (Full HD)
  proposal/p01.jpg … p19.jpg                  ← cadangan halaman booklet
README.md
```

## Update bulanan (cukup timpa file)

1. Buka repository di github.com.
2. Klik **Add file → Upload files**.
3. Seret **index.html** yang baru → **Commit changes**. File lama otomatis tertimpa.
4. Hanya jika PDF / video berubah: masuk ke folder `assets`, lalu upload file baru dengan **nama yang sama persis**.
5. Tunggu ± 1–2 menit, lalu refresh halaman (Ctrl+F5).

Nama file dan folder jangan diubah, supaya link dan tombol unduh tetap berfungsi.
